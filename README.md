# Lanterna do Brunão

Abra index.html no navegador ou use a extensão Live Server no VS Code.
HTML, CSS e JavaScript estão reunidos no index.html. Não precisa instalar dependências.

## GitHub Pages
Extraia o ZIP e abra a pasta Lanterna-do-Brunao no VS Code.
Envie index.html e este README.md para a raiz do repositório.
No GitHub: Settings > Pages > Deploy from a branch > main > / (root) > Save.

O Pix é demonstrativo e não realiza cobranças. A luz é gerada pela tela, não pelo flash.
